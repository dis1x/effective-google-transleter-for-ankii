# **How to install**
1. Visit Decstop version Ankii
2. ```Press ctrl+shift+a```
3. Click on "Get Add-ons"
4. Enter: 
	>1536291224
5. Click once on Google Translate
6. Click on "View Files"
7. Replase the file ```__init__.py``` with the downloaded file
8. Restart Ankii

---

# **Settings:**
1. Open Ankii Decstop
2. click "Browse"
3. Click on any card
4. On the opened card, click Fields and add new fields with your languages
   
   <img width="450" height="600" alt="image" src="https://github.com/user-attachments/assets/9bf162ed-7a47-47f0-b0d2-088112d4bc06" />


5. Save
6. Next, click Cards
7. In the Back Template, before or after the line where it says ```"class=content"```  add the line
   
    ```<div class="content">{{"название_поля_из_прошлого_шага"}}</div>```
   
<img width="450" height="600" alt="image" src="https://github.com/user-attachments/assets/058c88ee-9d27-4d06-8d55-ccdc329ec78b" />

5. Wrap the 2 lines with ```class="content"``` in a div with any class name
    
    <img width="447" height="609" alt="image" src="https://github.com/user-attachments/assets/9f6b718f-b6a4-446c-87db-7777a8541846" />

5. Click the next button ```"Styling"```
6. Write ```".название_класса" {display: flex;}```
    
  <img width="466" height="738" alt="image" src="https://github.com/user-attachments/assets/eaf7a5d9-b475-4fc7-91b7-e43b8ad6d4c2" />
  
5. Save and close the card settings
6. In the general card menu, click on any card and then press Ctrl+a
7. Click Edit and Google Translate
    
  <img width="450" height="600" alt="image" src="https://github.com/user-attachments/assets/723126ed-6b40-4d61-9a68-b5f46fd25ae4" />
  
5. In the menu that opens, in the ```"sourse field"``` ield, select the field from which the translation will be taken (usually "Content"); in the second field, specify the field you created
6. Select the language to be translated
7. In the ```"Format"``` field, select ```"HTML"```
    
  <img width="450" height="600" alt="image" src="https://github.com/user-attachments/assets/c6526cc9-f20e-46b4-8d24-a2e4550b1fcc" />

5. Click Start and wait
